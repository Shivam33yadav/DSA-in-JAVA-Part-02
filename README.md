# DSA in Java — Part 02 🚀

This repository contains my **Data Structures and Algorithms (DSA) practice in Java**, focused on **Arrays and important array-based problems**.

The goal of this repository is to strengthen problem-solving skills, improve algorithmic thinking, and build a strong foundation for coding interviews and competitive programming.

## 📚 Topics Covered

### Arrays

* Array Basics
* Passing Arrays as Function Arguments
* Linear Search
* Binary Search
* Reverse an Array
* Pairs in an Array
* Print All Subarrays
* Maximum Subarray Sum
* Maximum Subarray Sum using Prefix Sum
* Kadane's Algorithm
* Trapping Rain Water
* Buy and Sell Stocks

## ▶️ How to Run

Clone the repository:

```bash
git clone https://github.com/Shivam33yadav/DSA-in-JAVA-Part-02.git
```

Navigate to the project:

```bash
cd DSA-in-JAVA-Part-02
```

Compile a Java file:

```bash
javac AArrays.java
```

Run it:

```bash
java AArrays
```
